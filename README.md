# Form Editor

Editor web de un formulario ruso con escritura directa sobre las casillas del documento.

## Características

- Plantilla visual del formulario original.
- Campos superpuestos y alineados con cada casilla.
- Tipografía **Tinos**, compatible visualmente con Times New Roman y con alfabeto cirílico.
- Iconos de **Lucide**.
- Guardado local automático.
- Vista final con el botón **Listo**.
- Impresión / guardado como PDF desde el navegador.
- Diseño adaptable a móvil y escritorio.

## Uso

Abre `index.html` o publica el repositorio con GitHub Pages / cualquier hosting estático.

Los datos escritos se guardan solo en el almacenamiento local del navegador.
